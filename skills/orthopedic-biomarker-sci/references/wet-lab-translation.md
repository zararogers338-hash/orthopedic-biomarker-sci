# 实验验证与临床转化

实验按“补足哪一个证据缺口”选择。未确认场地、人员、样本、伦理和试剂条件时，输出实验设计与资源清单，不报告已完成。

## 分层证据与对应实验

| 拟支持的主张 | 可考虑的证据 | 仍不能推出 |
|---|---|---|
| 候选在组织中表达异常 | 独立供体组织的 RNA/蛋白检测，定位与盲法评分 | 外周血可测或临床诊断有效 |
| 候选来自某细胞群 | 单细胞线索＋蛋白定位/适当细胞实验 | 该细胞是唯一来源或通信已发生 |
| 候选进入滑液/血液且可稳定检测 | 相应介质中经验证的检测方法、前处理与批次性能 | 已适用于早诊或预测进展 |
| 候选关联临床状态 | 目标人群中独立样本、合理参考标准、混杂控制 | 机制因果或临床效用 |
| 候选调节功能 | 合适细胞模型中扰动、功能读出、特异性与可行的救援证据 | 人体疗效、药物安全或治疗获益预测 |
| 候选改善临床决策 | 临床增量、可靠外部评价及更进一步的效用研究 | 仅靠计算AUC或细胞实验不能兑现 |

## 骨关节炎路线的最小可解释证据包

**技术可行性先行**：确认候选 RNA/蛋白在目标模型或介质中可检测。按试剂及平台验证检测范围、精密度和特异性，避免用低于定量限的值制造分组差异。

**独立样本验证**：若能获得人软骨/滑膜，明确供体、部位、病理分级及对照来源；同一供体的多块组织使用配对/聚类处理。若拟定位滑液标志物，优先验证滑液；滑液是需穿刺获得的样本，不称为无创血液检测。

**功能验证**：从人原代软骨细胞或与问题匹配的模型评估候选；如果使用细胞系、炎症刺激或高剂量重组蛋白，说明外推范围。选择与假设相符的基质代谢、分泌、存活或其他功能终点，不固定要求所有通路指标。

扰动可采用适合条件的遗传或药理方法；配套载体/阴性/溶剂和必要的阳性对照。机制主张需要靶点改变确认、相关功能改变及足够的特异性证据；单一抑制剂效应或仅 qPCR 改变不足以证明完整机制。救援实验的形式由可行性与待证关系决定。

**动物研究按需**：只有当研究主张需要整体疾病环境，且可用条件允许时加入；不为提高图数默认增加。实际开展前需要相应审批与实验设计，报告遵循 [ARRIVE 2.0](https://arriveguidelines.org/arrive-guidelines)。

## 实验设计必须落实的细节

- 实验单位：独立供体/动物/适当独立培养批次；技术复孔不是新增生物学 n。
- 主要终点：预先选择与效应估计方法一致的一个主要问题，其余明确为次要/探索。
- 样本量：依据有意义效应、可信变异、功效或精度目标以及失败率；无依据时先做技术先导，不能假定每组3个足够。
- 批次与分配：病例/对照及处理组在可行范围内平衡板位、检测批次和执行顺序；随机化与盲法按任务落实。
- 前分析：采样部位、处理时长、保存、冻融、血清/血浆类型、滑液粘度及基质干扰、溶血、用药与合并症按所用介质登记。
- 质量控制：细胞身份/污染、试剂批号、抗体特异性、原始显微图和未裁剪印迹、仪器输出与排除规则按实验类型保存。
- 因果解释：处理导致普遍毒性时不能把所有下游下降解释成靶向改善；需检验活性与特异性。

## 继续与停止条件

无法稳定检测时先修正检测或放弃该介质；独立样本不复现时报告区间和异质性，不凭显著与否简单合并；扰动未改变功能时缩窄机制结论；平台或伦理无法满足时调整路线与时间。

临床转化、机制验证和分析性能分别判断，不要求所有证据都阳性。现有公开实验可作为支持，但应明确是他人数据再分析，是否足够满足具体稿件仍需按主张与期刊要求评估。

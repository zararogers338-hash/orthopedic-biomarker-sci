# 稿件与投稿质控

## 从证据写作

英文题目按实际设计选词。横断面研究写 association/characterization；未作纵向验证不写 predicts progression；无目标体液测量不写 circulating biomarker；单一分子层不写 multi-omics；独立验证不足不写 clinically validated。

摘要结果只使用已产生且核查的结果。尚在规划时可写方案摘要，不填写假想效应、P值、AUC或实验结论。创新陈述需与已检索原始研究逐项比较。

每个主要主张连接来源/数据、代码、结果表、图号和局限。建议形成“临床问题→发现→独立复现→功能或检测验证→可支持的转化边界”的叙述，图数服从证据，不预先硬凑六张图。

## 报告规范按研究类型选择

| 实际设计 | 依据 | 边界 |
|---|---|---|
| 队列、病例–对照或横断面 | [STROBE](https://www.strobe-statement.org/) | 不是因果证明或质量评分 |
| 相对参考标准的诊断准确性 | [STARD 2015](https://www.bmj.com/content/351/bmj.h5527) | 需实际病例谱、参考标准、阈值与流程 |
| 个体诊断/预后的多变量模型 | [TRIPOD+AI](https://www.bmj.com/content/385/bmj-2023-078378) | 回归与机器学习均可适用；纯差异表达不强套 |
| 预测模型偏倚和适用性审计 | [PROBAST+AI](https://www.bmj.com/content/388/bmj-2024-082505) | 与报告规范互补 |
| 活体动物实验 | [ARRIVE 2.0](https://arriveguidelines.org/arrive-guidelines) | 不能代替伦理审批；不用于纯体外实验 |
| 系统综述、Meta分析或其他改选类型 | 在切换后核实对应最新规范 | 不因项目有文献检索就冒称系统综述 |

## 图表与数据完整性

图注说明独立 n、技术重复、分组、单位、效应/不确定性、检验、多重比较与排除。细胞数与供体数分开。保留原图、可编辑图源和完整输出；不使用生成图像冒充显微图、条带或实验数据。

文献核对题目、作者、年份、DOI/PMID、原始结论和更正/撤稿信息。文献管理记录实际阅读范围，二手综述不能代替原实验出处。

## 投稿材料

先读 [目标期刊](target-journal.md)，再打开实时指南。准备主文、图表、补充材料、适用报告清单、图文摘要、cover letter、作者贡献、利益冲突、资助、伦理/同意、数据与代码可用性声明。没有伦理号或同意材料就标明待落实，不编造。

作者贡献按实际工作确认；推荐审稿人需真实身份、专业匹配与无利益冲突，不制造邮箱或推荐关系。AI使用按期刊当期政策如实披露，不把AI列为作者。

Cover letter 说明临床问题、证据增量、特刊适配和真实验证层级，不写保证接受、独家首创或未做过的验证。数据公开需要检查授权、许可和隐私，不上传未经批准的患者数据。

投稿前重新核对截止、特刊选择、费用、当前索引与单位认可条件。用户仅要求建skill和规划时，止于本地可审阅材料；不自动联系编辑或提交。

## 返修

逐条回复采用“意见→处理→新增证据→具体修改位置”。把可直接修正的文字、可完成的分析和需新增实验分开安排。不同意时给方法依据和证据，不用礼貌句替代实质回答。

无法完成的验证如实说明并收缩结论。不能在回复中声称实验已完成而正文/原始记录缺失，也不能用新终点替换原主要终点而不说明变更。

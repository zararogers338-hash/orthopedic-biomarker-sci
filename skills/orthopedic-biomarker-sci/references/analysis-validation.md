# 数据分析与验证

## 下载前的数据审计

建立 accession → 原始论文 → 招募中心/期间 → 供体 → 标本 → 文件 的关系。核实 SuperSeries/SubSeries、重复上传、样本排除、配对区域、同人不同组织和多组学重用。未知字段写未知，GEO 的 Samples 数不自动等于供体数。

先核查原始研究及样本页，再下载必要矩阵与元数据。实际分析前逐项核验样本名、计量单位、基因标识、处理流程、疾病/对照定义、批次、协变量、许可和访问条件。公共数据不等于所有用途无条件许可。

## 单细胞

1. 按供体保留来源，检查池化是否可拆回供体、每人质量和细胞类型覆盖。没有供体标签时可做有限图谱探索，不能制造疾病组的生物学重复。
2. 质控阈值依据平台与分布决定，保留剔除数量和理由；不要为获得目标细胞群而反复移动阈值。
3. 注释用多个可信标记与组织知识，保留模糊群和双细胞判断；整合主要用于对齐/可视化，疾病差异分析采用适合统计模型的数据层。
4. 条件比较优先供体×细胞类型 pseudobulk，或明确建模供体依赖的方法。模型考虑配对与协变量，报告供体 n 和细胞数两个层级。
5. 某细胞群仅在一组或极少供体中出现时，区分丰度变化和细胞内表达变化；缺失细胞类型不能简单填零后当表达变化。
6. 轨迹和配体–受体推断只能提出机制线索，不能凭拟时序证明患者病程或凭配对表达证明信号传导。

方法依据：[Confronting false discoveries in single-cell differential expression](https://www.nature.com/articles/s41467-021-25960-2)。它支持考虑生物学重复，不意味着某个软件或算法在所有数据上都最优。

## Bulk 与跨队列

- 区分原始 counts、标准化连续表达和微阵列，选用匹配数据分布的方法；不用已 log 转换值冒充 counts。
- 配对模型应使用供体信息；年龄、性别、BMI、药物、部位、组织损伤分级等按实际可得性处理，不能凭空补全。
- 优先各研究内估计效应再比较方向与异质性；合并分析须有合理统一尺度和设计。疾病与批次完全混杂时，批次校正不能凭空识别疾病效应。
- 同一关节相对完整软骨仍来自 OA 患者。健康供体、尸体对照、创伤对照、半月板手术人群分别说明，不能统一命名健康人。
- 跨组织复现、跨物种支持、技术平台重复和独立临床验证分别命名。

## 多组学

单细胞＋bulk＋qPCR 仍是转录层证据。蛋白组/代谢组等需有实际数据与质控；少数候选蛋白的 ELISA 或 Western blot 是靶向验证，不能自动升级为蛋白组学。

配对数据核对同一供体、组织与时间，考虑各层缺失与测量误差。非配对转录组和滑液蛋白组可做候选层证据整合，但不拼成虚构的患者联合矩阵。若第二组学已参与筛选，它属于发现链条，不再是完全独立的候选验证。

## 预测模型仅在临床问题需要时建立

先锁定外部评价集，并披露其结果是否已参与研究设计。每位患者的全部细胞、切片、重复采样留在同一分组。

以下操作均在训练流程内拟合：差异/特征筛选、填补、缩放、重采样、批次处理参数、超参数和阈值。调参需适当内部重采样，评价结构与调参结构分开。不要合并训练与测试先去批次后声称完全独立。外部集用于重新校准时，说明模型更新并再安排合适评价。

从简洁的临床基线开始；复杂模型只有在样本量和新增价值支持时采用。比较基线与“基线＋指标”，给出不确定性、校准及适当总体误差。净获益需有实际决策阈值和合适人群；不能把高度选择的病例–对照数据直接转成患病人群绝对风险、预测值或未经调整的决策曲线。

不能以固定 AUC 门槛判定成功，也不要为获得最好结果在评价集反复选模型。候选与临床基线无增量是有效结果。

适用依据：[TRIPOD+AI](https://www.bmj.com/content/385/bmj-2023-078378)、[PROBAST+AI](https://www.bmj.com/content/388/bmj-2024-082505)。模型研究按这两类工具分别进行报告和偏倚检查，不把报告清单当质量证明。

## 样本量与敏感性

公共数据先评估有效供体、事件数、缺失与效应区间；无法支撑复杂模型时简化目标。开发样本量需考虑参数数、结局分布及预期性能；评价样本量围绕区分度、校准等目标精度设计，不能机械使用“每变量10事件”或“100例验证”。参见[外部评价样本量方法](https://www.bmj.com/content/384/bmj-2023-074821)。

按实际风险预设敏感性分析：排除可疑重叠供体、配对设计、年龄/性别混杂、不同对照定义、留一研究、平台差异、细胞组成。不要无目的重复算法或在阴性后删去不利队列。

## 可复现交付

原始数据只读；处理表与图均由脚本生成。保留下载URL、访问日期、许可、SHA256、样本映射、软件/包版本、随机种子、运行命令与日志。R 工程可用 renv，Python 可用环境锁文件；根据实际工具选择，不同时强制两套。

在真实小规模输入上验证样本映射和设计矩阵，再扩展。检查输出供体数、分组、量纲和排除是否与方案一致。图中 n、正文 n、统计 n 必须相符；保留完整效应表和失败结果。

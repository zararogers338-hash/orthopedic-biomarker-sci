# 骨科生物标志物 SCI 研究工程规划

建立日期：2026-10-14。当前完成的是技能与研究规划，尚未完成数据分析、实验、完整新颖性核查或论文投稿。

## 目标与首选路线

目标是围绕 BioFactors 的 **Next-Generation Biomarkers: From Multi-Omics Discovery to Clinical Translation** 特刊，完成一个证据可复核、能由公共数据启动并补充实验的骨科研究。用户已选定“公共数据＋可补充实验”，疾病方向依特刊适配与数据可行性选择。

建议优先：**膝骨关节炎中具有细胞来源依据的分泌或细胞外基质相关因子，开展跨队列发现、滑液蛋白证据整合与功能验证。** 椎间盘退变为备选；骨质疏松待临床表型与实验资源更明确后再比较。

拟研究问题：哪些候选因子在供体层面的软骨细胞分析中显示稳定关联，在其他软骨队列与滑液蛋白组中获得支持，并能通过独立样本或功能实验检验？具体靶点由新颖性、效应稳定性、可检测性及实验可行性决定，不预先选定热门通路。

暂定工作题名：**膝骨关节炎候选分泌因子的跨队列发现与功能验证**。若真实第二组学数据审计通过，再在论文标题中体现跨组学整合。此阶段不使用“早期诊断”“预测进展”或“临床验证完成”等表述。

## 实验资源的最低决策清单

第一阶段确认：能否获取独立膝OA软骨/滑膜或滑液，何种对照与临床资料；是否有原代细胞或合适模型；qPCR、蛋白检测、免疫定位和干预能力；伦理负责人和办理周期；可承受预算与人员时间。

先从可测性与直接验证开始，再按主张增加机制实验。若声称滑液蛋白候选，需要滑液或可靠的相应介质证据；若只完成组织和细胞实验，稿件定位为组织相关候选与功能研究。动物实验并非自动必做。

样本量根据主要终点与精度/功效论证，技术复孔不代替供体；当前资源未明确，不虚报固定例数或价格。预算按公开数据计算/存储、样本与伦理、试剂检测、干预、可选动物、发表费用分项询价，未报价项保持待确认。

## 主要风险及处理

| 发现的问题 | 决定 |
|---|---|
| 供体/分组无法核实，或病例与批次完全混杂 | 暂停相关疾病推断，补资料或换数据，不凭算法修饰 |
| 第二组学不可重分析或来源偏倚主导结果 | 改作跨尺度转录组＋功能路线，或找合适新分子层；调整标题 |
| 候选与已有工作高度重复 | 评估临床用途/检测/机制的真实新增价值，不仅更换算法 |
| 无独立评价集或实验条件 | 收缩为探索性研究，重新评估目标期刊；必要时转题 |
| 无法取得体液或纵向数据 | 不声称无创诊断或预后，保留组织机制结论 |
| 实验阴性或不复现 | 报告效应区间与异质性，按预设规则调整，保留负结果 |
| 特刊关闭或周期不匹配 | 以证据强度选择替代期刊，不为赶日期删减必要验证 |
